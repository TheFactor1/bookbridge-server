Bookbridge server setup

first-run wizard

Answer a few questions. This writes the config, starts the services you pick, tests them, and gives your Kindle a pairing code. Nothing here is permanent — you can re-run it.

1 · This machine's address

The address your Kindle reaches this computer at — your Tailscale IP (e.g. 100.x.x.x) or a hostname on your network.

2 · What to run

Shelfmark itself always runs. Turn on what you want; each is optional and can be added later.

3 · Configure & start

Writes the config and brings up the services you chose. This can take a minute the first time.
